# Mech Arena — Canvas Top-Down Mech Shooter Game

Mech Arena is a lightweight, browser-based top-down mech shooter game built with plain JavaScript and HTML5 Canvas. In this open source project, you pilot a mech through endless waves of enemy mechs, using mouse aiming and WASD/arrow key movement. The game features a wave-based progression system, multiple enemy types (scouts and heavies), health bars, particle effects, screen shake, floating score text, and a retro-style HUD. It is implemented as a single-page application with no external dependencies, making it easy to run locally or embed anywhere. This project is ideal for learning canvas game development, understanding game loops, or serving as a base for your own mech-themed game experiments.

## Install

1. Clone or download this repository to your local machine.
2. Ensure you have the three files: `index.html`, `style.css`, and `game.js` in the same directory.
3. No build tools, package managers, or external libraries are required — the project runs directly in any modern web browser.

## Use

1. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
2. Click the **DEPLOY** button on the start screen to begin the game.
3. Control your mech:
   - **WASD / Arrow Keys**: Move your mech around the arena.
   - **Mouse**: Aim your weapon turret.
   - **Click / Hold Mouse Button**: Fire your weapon at enemies.
4. Survive waves of enemy mechs that spawn from the edges of the arena. Each wave increases difficulty with faster and tougher enemies.
5. Your hull integrity (health) is shown in the top-left HUD bar. If it reaches zero, your mech is destroyed, and you can restart by clicking **REDEPLOY**.
6. Earn points by destroying enemies — scouts give 10 points, heavies give 20 points. Watch your score and current wave number in the HUD.
